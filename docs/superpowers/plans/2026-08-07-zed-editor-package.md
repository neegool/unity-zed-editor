# com.neegool.ide.zed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert this copy of Unity's `com.unity.ide.visualstudio` package into `com.neegool.ide.zed`, a standalone UPM package that registers [Zed](https://zed.dev) as Unity's external script editor and generates the `.csproj`/`.sln` files `roslyn-language-server` needs.

**Architecture:** Keep the first-party three-layer shape — `ZedEditor : IExternalCodeEditor` → `Discovery` → `IZedInstallation`, with `ProjectGeneration/` vendored unchanged. Replace the Visual Studio discovery and launch layer with a Zed equivalent; delete the COM, vswhere, UDP-messaging and test-runner subsystems entirely.

**Tech Stack:** C# 9, Unity 2021.3+ Editor API, `Unity.CodeEditor.IExternalCodeEditor`, SimpleJSON (vendored), Zed CLI 1.14+.

**Spec:** `docs/superpowers/specs/2026-08-07-zed-editor-package-design.md`

## Global Constraints

- Package id `com.neegool.ide.zed`, `displayName` `Zed Editor`, `version` `1.0.0`, `unity` `2021.3`, **zero dependencies**.
- Namespace `Neegool.Unity.Zed.Editor` everywhere. Assembly definition `Neegool.Zed.Editor`.
- Indentation is **tabs** in `.cs` files — match the existing files exactly.
- No identifier, namespace, string, or comment may reference Visual Studio, VS Code, VSTU, or Microsoft licensing except where the retained MIT copyright header requires it (`ProjectGeneration/`, `SimpleJSON.cs`, and other kept files keep their original headers — this is a fork of MIT-licensed code and the attribution stays).
- `.zed/settings.json` is written with `new UTF8Encoding(encoderShouldEmitUTF8Identifier: false)` — **no BOM**. `.csproj`/`.sln` keep their BOM (`FileIOProvider.cs` uses `Encoding.UTF8`); do not change that.
- Every task ends with `tools/compile-check.sh` passing.
- Unity meta files: when deleting `Foo.cs`, delete `Foo.cs.meta`. When renaming, move both so the GUID is preserved. New files get metas generated by Unity on first import.

```csharp
/*---------------------------------------------------------------------------------------------
 *  Copyright (c) Microsoft Corporation. All rights reserved.
 *  Licensed under the MIT License. See License.txt in the project root for license information.
 *--------------------------------------------------------------------------------------------*/
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text.RegularExpressions;
using Unity.CodeEditor;
using IOPath = System.IO.Path;

namespace Neegool.Unity.Zed.Editor
{
	internal interface IZedInstallation
	{
		string Path { get; }
		bool SupportsAnalyzers { get; }
		Version LatestLanguageVersionSupported { get; }
		string[] GetAnalyzers();
		CodeEditor.Installation ToCodeEditorInstallation();
		bool Open(string path, int line, int column, string solutionPath);
		IGenerator ProjectGenerator { get; }
		void CreateExtraFiles(string projectDirectory);
	}

	internal class ZedInstallation : IZedInstallation
	{
		private static readonly IGenerator _generator = GeneratorFactory.GetInstance(GeneratorStyle.SDK);

		public string Name { get; set; }
		public string Path { get; set; }
		public Version Version { get; set; }

		public IGenerator ProjectGenerator => _generator;

		// Gates the whole analyzer block in ProjectGeneration.SetAnalyzerAndSourceGeneratorProperties,
		// which also emits Unity's own RoslynAnalyzerDllPaths, the ruleset, the .editorconfig and any
		// csc.rsp analyzers. Must stay true even though Zed ships no analyzers of its own -
		// returning false silently strips the user's analyzer configuration from every csproj.
		public bool SupportsAnalyzers => true;

		// Analyzers shipped *by the IDE*. Zed has no equivalent to the vstuc extension.
		public string[] GetAnalyzers() => Array.Empty<string>();

		// A ceiling, not a request: GetLangVersion takes min(this, Unity's supported version),
		// so Unity's compiler stays the governing constraint.
		public Version LatestLanguageVersionSupported => new Version(13, 0);

		public CodeEditor.Installation ToCodeEditorInstallation()
		{
			return new CodeEditor.Installation { Name = Name, Path = Path };
		}

		public void CreateExtraFiles(string projectDirectory)
		{
			// Filled in by Task 6.
		}

		public bool Open(string path, int line, int column, string solutionPath)
		{
			line = Math.Max(1, line);
			column = Math.Max(0, column);

			var projectDirectory = IOPath.GetDirectoryName(solutionPath);
			var arguments = Quote(projectDirectory);

			if (!string.IsNullOrEmpty(path))
				arguments += " " + Quote($"{path}:{line}:{column}");

			try
			{
				ProcessRunner.Start(ProcessRunner.ProcessStartInfoFor(Path, arguments, redirect: false));
				return true;
			}
			catch (Exception e)
			{
				UnityEngine.Debug.LogError($"Unable to launch Zed at {Path}: {e.Message}");
				return false;
			}
		}

		private static string Quote(string value)
		{
			return $"\"{value}\"";
		}

		// Zed ships two executables: the multi-hundred-megabyte GUI at <install>/Zed.exe and a small
		// CLI launcher at <install>/bin/Zed.exe. Only the launcher parses path:line:column, and the
		// GUI is what a user browsing to the install folder will pick.
		internal static string NormalizeToLauncher(string editorPath)
		{
			if (string.IsNullOrEmpty(editorPath))
				return editorPath;

#if UNITY_EDITOR_OSX
			if (editorPath.EndsWith(".app", StringComparison.OrdinalIgnoreCase))
			{
				var cli = IOPath.Combine(editorPath, "Contents", "MacOS", "cli");
				return File.Exists(cli) ? cli : editorPath;
			}

			return editorPath;
#elif UNITY_EDITOR_WIN
			var directory = IOPath.GetDirectoryName(editorPath);
			if (string.IsNullOrEmpty(directory))
				return editorPath;

			if (string.Equals(IOPath.GetFileName(directory), "bin", StringComparison.OrdinalIgnoreCase))
				return editorPath;

			var launcher = IOPath.Combine(directory, "bin", IOPath.GetFileName(editorPath));
			return File.Exists(launcher) ? launcher : editorPath;
#else
			// The Linux distribution ships the launcher directly.
			return editorPath;
#endif
		}

		private static readonly Regex VersionExpression = new Regex(@"\d+\.\d+\.\d+", RegexOptions.Compiled);

		// `zed --version` prints e.g. "Zed 1.14.2 02abf5b0... - C:\...\Zed.exe"
		internal static bool TryParseVersion(string output, out Version version)
		{
			version = null;

			if (string.IsNullOrEmpty(output))
				return false;

			var match = VersionExpression.Match(output);
			return match.Success && Version.TryParse(match.Value, out version);
		}

		private static bool IsCandidateForDiscovery(string path)
		{
#if UNITY_EDITOR_OSX
			if (Directory.Exists(path) && path.EndsWith(".app", StringComparison.OrdinalIgnoreCase))
				return true;
#endif
			return File.Exists(path) && IOPath.GetFileNameWithoutExtension(path).Equals("zed", StringComparison.OrdinalIgnoreCase);
		}

		public static bool TryDiscoverInstallation(string editorPath, out IZedInstallation installation)
		{
			installation = null;

			if (string.IsNullOrEmpty(editorPath))
				return false;

			if (!IsCandidateForDiscovery(editorPath))
				return false;

			var launcher = NormalizeToLauncher(editorPath);
			var version = QueryVersion(launcher);

			installation = new ZedInstallation
			{
				Name = "Zed" + (version != null ? $" [{version.ToString(3)}]" : string.Empty),
				Path = launcher,
				Version = version ?? new Version()
			};

			return true;
		}

		private static Version QueryVersion(string launcher)
		{
			try
			{
				var result = ProcessRunner.StartAndWaitForExit(launcher, "--version", timeoutms: 2000);
				if (result.Success && TryParseVersion(result.Output, out var version))
					return version;
			}
			catch (Exception)
			{
				// A Zed we cannot version is still a Zed we can launch.
			}

			return null;
		}

		public static IEnumerable<IZedInstallation> GetZedInstallations()
		{
			foreach (var candidate in GetCandidates().Distinct())
			{
				if (TryDiscoverInstallation(candidate, out var installation))
					yield return installation;
			}
		}

		private static IEnumerable<string> GetCandidates()
		{
#if UNITY_EDITOR_WIN
			var localAppData = Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData);
			var programFiles = Environment.GetFolderPath(Environment.SpecialFolder.ProgramFiles);
			var userProfile = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);

			yield return IOPath.Combine(localAppData, "Programs", "Zed", "bin", "Zed.exe");
			yield return IOPath.Combine(programFiles, "Zed", "bin", "Zed.exe");
			yield return IOPath.Combine(userProfile, "scoop", "apps", "zed", "current", "bin", "zed.exe");
#elif UNITY_EDITOR_OSX
			var userProfile = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);

			yield return "/Applications/Zed.app";
			yield return "/Applications/Zed Preview.app";
			yield return IOPath.Combine(userProfile, "Applications", "Zed.app");
#else
			var userProfile = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);

			yield return "/usr/bin/zed";
			yield return "/usr/local/bin/zed";
			yield return IOPath.Combine(userProfile, ".local", "bin", "zed");
			yield return "/var/lib/flatpak/exports/bin/dev.zed.Zed";
#endif

			foreach (var fromPath in GetCandidatesFromPath())
				yield return fromPath;
		}

		private static IEnumerable<string> GetCandidatesFromPath()
		{
			var pathVariable = Environment.GetEnvironmentVariable("PATH");
			if (string.IsNullOrEmpty(pathVariable))
				yield break;

#if UNITY_EDITOR_WIN
			var names = new[] { "zed.exe", "Zed.exe" };
#else
			var names = new[] { "zed" };
#endif

			foreach (var directory in pathVariable.Split(IOPath.PathSeparator))
			{
				if (string.IsNullOrEmpty(directory))
					continue;

				foreach (var name in names)
				{
					string candidate;

					try
					{
						candidate = IOPath.Combine(directory, name);
					}
					catch (ArgumentException)
					{
						// PATH can contain entries with characters invalid for a path.
						break;
					}

					if (File.Exists(candidate))
						yield return candidate;
				}
			}
		}

		public static void Initialize()
		{
		}
	}
}

```csharp
/*---------------------------------------------------------------------------------------------
 *  Copyright (c) Microsoft Corporation. All rights reserved.
 *  Licensed under the MIT License. See License.txt in the project root for license information.
 *--------------------------------------------------------------------------------------------*/
using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text;
using SimpleJSON;
using IOPath = System.IO.Path;

namespace Neegool.Unity.Zed.Editor
{
	internal static class ZedSettings
	{
		// Explicit, not inherited from a default: FileIOProvider writes .csproj/.sln *with* a BOM
		// (Encoding.UTF8), which is correct for MSBuild. Zed's settings.json must not have one.
		private static readonly UTF8Encoding NoBomUtf8 = new UTF8Encoding(encoderShouldEmitUTF8Identifier: false);

		private static readonly string[] LanguageServers = { "roslyn", "!csharp-ls", "!omnisharp", "..." };

		private static readonly string[] FileScanExclusions =
		{
			"**/.git",
			"**/.svn",
			"**/.hg",
			"**/.DS_Store",
			"**/Thumbs.db",
			"**/Library",
			"**/Temp",
			"**/Obj",
			"**/Logs",
			"**/Build",
			"**/Builds",
			"**/UserSettings",
			"**/MemoryCaptures",
			"**/*.meta"
		};

		// background_analysis is scoped to openFiles: full-solution analysis on a Unity project
		// is prohibitively slow.
		private const string DefaultContent = @"{
    ""languages"": {
        ""CSharp"": {
            ""language_servers"": [""roslyn"", ""!csharp-ls"", ""!omnisharp"", ""...""]
        }
    },
    ""lsp"": {
        ""roslyn"": {
            ""settings"": {
                ""csharp|background_analysis"": {
                    ""dotnet_analyzer_diagnostics_scope"": ""openFiles"",
                    ""dotnet_compiler_diagnostics_scope"": ""openFiles""
                },
                ""csharp|projects"": {
                    ""dotnet_enable_automatic_restore"": true
                }
            }
        }
    },
    ""file_scan_exclusions"": [
        ""**/.git"",
        ""**/.svn"",
        ""**/.hg"",
        ""**/.DS_Store"",
        ""**/Thumbs.db"",
        ""**/Library"",
        ""**/Temp"",
        ""**/Obj"",
        ""**/Logs"",
        ""**/Build"",
        ""**/Builds"",
        ""**/UserSettings"",
        ""**/MemoryCaptures"",
        ""**/*.meta""
    ]
}";

		public static void CreateOrPatch(string projectDirectory)
		{
			try
			{
				var zedDirectory = IOPath.Combine(projectDirectory.NormalizePathSeparators(), ".zed");
				Directory.CreateDirectory(zedDirectory);

				var settingsFile = IOPath.Combine(zedDirectory, "settings.json");
				if (!File.Exists(settingsFile))
				{
					File.WriteAllText(settingsFile, DefaultContent, NoBomUtf8);
					return;
				}

				Patch(settingsFile);
			}
			catch (IOException)
			{
				// A non-writable .zed directory must not fail project generation.
			}
		}

		private static void Patch(string settingsFile)
		{
			try
			{
				var settings = JSONNode.Parse(File.ReadAllText(settingsFile));

				var patched = PatchLanguageServers(settings);
				patched |= PatchRoslynSettings(settings);
				patched |= PatchFileScanExclusions(settings);

				if (!patched)
					return;

				File.WriteAllText(settingsFile, settings.ToString(aIndent: 4), NoBomUtf8);
			}
			catch (Exception)
			{
				// A malformed user settings.json must not break opening files.
			}
		}

		// Written only when absent: a user who deliberately switched to csharp-ls keeps that choice
		// across regenerates.
		private static bool PatchLanguageServers(JSONNode settings)
		{
			var csharp = GetOrCreateObject(GetOrCreateObject(settings, "languages"), "CSharp");

			if (csharp["language_servers"] is JSONArray)
				return false;

			var servers = new JSONArray();
			foreach (var server in LanguageServers)
				servers.Add(server);

			csharp["language_servers"] = servers;
			return true;
		}

		private static bool PatchRoslynSettings(JSONNode settings)
		{
			var roslynSettings = GetOrCreateObject(GetOrCreateObject(GetOrCreateObject(settings, "lsp"), "roslyn"), "settings");

			var patched = SetIfAbsent(GetOrCreateObject(roslynSettings, "csharp|background_analysis"), "dotnet_analyzer_diagnostics_scope", "openFiles");
			patched |= SetIfAbsent(GetOrCreateObject(roslynSettings, "csharp|background_analysis"), "dotnet_compiler_diagnostics_scope", "openFiles");
			patched |= SetIfAbsent(GetOrCreateObject(roslynSettings, "csharp|projects"), "dotnet_enable_automatic_restore", true);

			return patched;
		}

		private static bool PatchFileScanExclusions(JSONNode settings)
		{
			var existing = settings["file_scan_exclusions"] as JSONArray;
			if (existing == null)
			{
				existing = new JSONArray();
				settings["file_scan_exclusions"] = existing;
			}

			var present = new HashSet<string>(existing.Children.Select(child => child.Value));
			var missing = FileScanExclusions.Where(exclusion => !present.Contains(exclusion)).ToArray();

			foreach (var exclusion in missing)
				existing.Add(exclusion);

			return missing.Length > 0;
		}

		private static JSONObject GetOrCreateObject(JSONNode parent, string key)
		{
			if (parent[key] is JSONObject existing)
				return existing;

			var created = new JSONObject();
			parent[key] = created;
			return created;
		}

		private static bool SetIfAbsent(JSONObject target, string key, string value)
		{
			if (target[key] is JSONString)
				return false;

			target[key] = value;
			return true;
		}

		private static bool SetIfAbsent(JSONObject target, string key, bool value)
		{
			if (target[key] is JSONBool)
				return false;

			target[key] = value;
			return true;
		}
	}
}

```markdown
# Zed Editor for Unity

Unity package that registers [Zed](https://zed.dev) as an external script editor.

C# language support in Zed comes from Zed's own C# extension, which uses
`roslyn-language-server`. That server needs `.csproj`/`.sln` files to resolve
Unity's assemblies, defines and package references — this package generates them.

## Requirements

- Unity 2021.3 or newer
- Zed 1.14 or newer
- Zed's C# extension
- .NET SDK (required by `roslyn-language-server`)

## Install

Add to `Packages/manifest.json`:

```json
"com.neegool.ide.zed": "https://github.com/<owner>/com.neegool.ide.zed.git"
```

## Use

1. *Edit > Preferences > External Tools* → set **External Script Editor** to Zed.
2. Tick the package sources you want `.csproj` files for.
3. *Tools > Zed > Regenerate Project Files*.

Double-clicking a script, or a compile error in the Console, opens Zed at the
right line.

## What it generates

| Path | Contents |
| --- | --- |
| `<Project>.sln`, `*.csproj` | SDK-style projects for `roslyn-language-server` |
| `.zed/settings.json` | Roslyn configuration and Unity file-scan exclusions |

`.zed/settings.json` is merged, not overwritten. Existing keys are preserved —
including `languages.CSharp.language_servers`, so switching to a different C#
language server survives regeneration.

## Not included

- No Unity ↔ Zed IPC bridge (play mode control, test runner). Zed's extension API
  is WASM-sandboxed and language-server shaped, so the socket protocol Visual
  Studio uses has no counterpart.
